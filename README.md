# Well Art, сайт-витрина

Статический preview сайта мебельного салона Well Art в Махачкале. Проект построен на Astro и TypeScript.

## Команды

```sh
corepack pnpm install
corepack pnpm dev
corepack pnpm build
corepack pnpm preview
```

Production-сборка появляется в `dist/`.

## Контент preview

- Категории, названия и артикулы товаров в `src/data/catalog.ts` придуманы для демонстрации структуры и должны быть согласованы или заменены перед публикацией.
- Фотографии временно загружаются с Unsplash и используются для закрытого визуального preview. Перед production их нужно заменить оригиналами салона и товаров с подтверждёнными правами.
- Цены, размеры, материалы, отделки, отзывы и неподтверждённые услуги намеренно не добавлены.
- Адрес, телефон, график и социальные ссылки сверены с карточкой Well Art в 2ГИС и официальным Taplink.
- Политика конфиденциальности является черновиком и требует реквизитов оператора и юридической проверки.

## Как добавить товар

Откройте `src/data/catalog.ts` и добавьте объект в массив `products`:

- `slug`: стабильный человекочитаемый URL латиницей;
- `name`: подтверждённое название;
- `sku`: артикул;
- `category`: slug существующей категории;
- `status`: `in-stock` или `made-to-order`;
- `description`: короткое предметное описание;
- `images`: массив путей к изображениям;
- `featured`: `true`, если товар нужен на главной.

Для production изображения лучше хранить локально в `public/images/products/<sku>/`. Подготовьте WebP/AVIF, сохраните пропорции исходника, не загружайте многомегабайтные оригиналы и используйте отдельный crop для первого экрана на мобильном.

## Перед публикацией

Замените временные фотографии и демо-каталог, подтвердите логотип, категории, дни работы, условия доставки, юридические реквизиты и домен. Затем проверьте WhatsApp-сообщения на реальном телефоне, canonical URL, sitemap, robots, 404 и production preview.
